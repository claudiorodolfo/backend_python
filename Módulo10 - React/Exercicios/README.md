# Exercícios — Módulo10 React

Use este diretório como **biblioteca de prática** junto com `Aulas/`.

## Como estudar

1. Leia a aula correspondente.
2. Faça os exercícios **sem olhar o gabarito do projeto** até tentar por conta própria.
3. Compare depois com:
   - `Projetos/Projeto1-React-Pessoas/` (CRUD + API)
   - `Projetos/Projeto2-Fullstack-Pessoas-Auth/` (JWT + rotas protegidas)
